# metis-webview-page

The packaged `WebView2` page presentation (METIS-WEBVIEW-RUST-001). One Rust
module owns both packaged pages' behavior — the calculation form's theme,
command menu, announced keyboard shortcuts, submit and typed reply rendering,
and the permission probe's bounded sequential capability requests — compiled
to WebAssembly through generated `wasm-bindgen` interop.

## Build

The WebAssembly loader is regenerated by the bounded build script:

```sh
python scripts/webview_page.py build
```

The script compiles this crate for `wasm32-unknown-unknown` under the audited
lock, runs the pinned `wasm-bindgen-cli`, and writes the packaged loader with
one mechanical auto-init suffix into `crates/metis-app/src/frontend/webview/
generated/`. The suffix exists because a `file://`-origin packaged page cannot
fetch sibling files; the loader therefore embeds the module bytes and calls
the generated `initSync` with them. Re-run the script to confirm the
committed loader still matches the source:

```sh
python scripts/webview_page.py check
```

The native target stays dependency-free and empty, so workspace-wide native
builds, tests and lint gates compile this crate unchanged.
