# Selected Rust command observations

The actual Windows 561189 form run retains native S-down/up (sequences
335/336, scan31/nonextended, Alt+Shift held, Handled=false), but does not
establish delivery to this document listener. This private observation closes
that evidential boundary; it does not correct or replace input delivery.

The native package adds one Form-only marker for the exact owned diagnostic
selection. The coordinator reads that marker once at mount; absence creates
no producer and adds no per-key metadata, stage, counter, or bridge reads.
The existing public page codec, request state, and lifecycle remain separate.

The initial Selected record follows the existing Ready publication. The
producer arms only from the existing resolved ThemeDark command, using the
original handler's single KeyboardMetadata read and accelerator resolution.
That first invocation starts with MetadataDecision, not an invented Entered.
Each later callback records real entry before its original Ready/metadata
checks, then records exact metadata/admission/decision and its original Result.
Trust is observed; it does not confer input or backend authority. Strings are
not truncated. A successful return establishes no DOM-value or rendered-frame
claim: no additional DOM reads or writes provide diagnostic evidence.

One shared Budget governs both producer encoding and native raw-byte receipt,
with their respective actual byte counts. N=128 and B=32768 include one finite
reserved terminal; its bound is derived by the shared codec. Thus the stream's
context-free JSON formatter obeys 2B+NE, where E is the actual native empty
envelope including LF. Native receiver counters need not equal canonical
producer bytes after the SDK serializes the JS object. Encoding, posting, or
terminal failure stays owned and disables diagnostics; it never calls the
functional failure renderer or changes the original handler Result.

The producer releases all session/application/producer borrows before actual
bridge publication. Ready-only native admission requires the existing Source
check first, explicit selection, current Form identity, sequence, and quota.
The closed versioned codec accepts equivalent JSON object order, whitespace,
and escaping, while rejecting unknown/duplicate fields and noncanonical integer
values. This matters because the real bridge parses Rust JSON into a JS object
before native SDK serialization.

For Escape outside an open menu, ClosingIntent is emitted before the original
CloseRequested post; no later diagnostic return is posted into Stopping.
Intent does not prove the functional post or native shutdown succeeds. Existing
CloseRequested/Stopped/Destroyed/resource observations remain the proof. An
external Stop adds no teardown message. Missing terminal, producer failure, or
quota prevents completeness/absence claims; positive metadata remains useful.

Portable tests exercise the real producer's arming, values, sequence, budget,
finite closure, exact accounting and typed failures. Codec tests establish
serialization and reserve laws. A real WASM build verifies integration; actual
selected/ordinary Windows journeys remain required and unchanged.
